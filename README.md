# Portfolio — Fase 1

Dashboard awal portofolio Lailatul Fitriyah menggunakan HTML, CSS, dan Vanilla JavaScript.

## Menjalankan
1. Ekstrak folder proyek.
2. Buka folder `portfolio-fase1` di Visual Studio Code.
3. Jalankan `index.html` menggunakan ekstensi Live Server, atau buka langsung di browser.

## Foto profil
Simpan foto formal milikmu dengan nama `profile.jpg` pada:
`assets/images/profile.jpg`

Disarankan menggunakan foto portrait dengan pencahayaan jelas. Website akan menampilkan placeholder jika foto belum tersedia.

## Yang sudah tersedia
- Navbar atas
- Sidebar collapsible pada desktop
- Sidebar drawer pada mobile
- Light/dark theme dengan preferensi tersimpan
- ID Card asimetris
- Dashboard dan project preview placeholder
- Responsive layout
- Reduced-motion support

## Catatan konten
Deskripsi, lokasi, akun media sosial, dan detail proyek masih berupa placeholder. Ganti hanya setelah konten dikonfirmasi.
